ایجاد خودکار یک پست‌تایپ سفارشی به نام «مرکز» (جمع: «مراکز») و درون‌ریزی گروهی از فایل اکسل/CSV با نه فیلد. فقط ۹ ستون اول خوانده می‌شود.

== Description ==

افزونه «معرفی شبکه ایده پردازی»:

* پست‌تایپ «مراکز» (مفرد: «مرکز»، slug: idea_center) را می‌سازد.
* پست‌ها همه فیلدهای پست عادی وردپرس را دارند: عنوان، ویرایشگر، نویسنده، تصویر شاخص، خلاصه، بازتاب‌ها، فیلدهای سفارشی، دیدگاه‌ها و اصلاحات.
* بخش «دسته بندی ها» برای افزودن و مدیریت دسته‌بندی‌های سلسله‌مراتبی (دستی، بدون ستون اکسل).
* فایل xlsx / xlsm / csv را آپلود و همه ردیف‌ها را یکجا به پست تبدیل می‌کند.
* نه فیلد را ذخیره می‌کند: «نام مراکز» در عنوان پست + ۸ متا (تعداد مراکز، تعداد استان، ایکون، آدرس، شماره تماس، آدرس وبسایت، نام شهر، نام استان).
* فقط ۹ ستون اول را می‌خواند و ستون‌های اضافه را نادیده می‌گیرد.
* گزارش کامل نتیجه: تعداد ایجادشده، به‌روزرسانی‌شده، ردیف‌های رد شده و خطاها به همراه شماره ردیف.

پارسر اکسل اختصاصی است و هیچ کتابخانه خارجی (مثل PhpSpreadsheet) لازم ندارد؛ فقط اکستنشن zip PHP.

== Installation ==

1. پوشه idea-network را در مسیر wp-content/plugins/ قرار دهید.
2. افزونه را از بخش «افزونه‌ها» فعال کنید.
3. از منوی «مراکز ← درون‌ریزی اکسل» استفاده کنید.

== Frequently Asked Questions ==

= آیا این فیلدها در المنتور قابل استفاده‌اند؟ =

بله. کلیدهای متا بدون زیرخط هستند و در پویاساز «فیلد سفارشی (Custom Field)» المنتور نمایش داده می‌شوند: `ei_center_count`، `ei_province_count`، `ei_icon`، `ei_address`، `ei_phone`، `ei_website`، `ei_city`، `ei_province_name`. «نام مراکز» در عنوان پست است. این کلیدها در بخش «مشخصات مرکز» نوشته شده‌اند.

با ویجت **Loop Grid** هم کار می‌کند: در پرس‌وجوی حلقه، نوع پست «مراکز» را انتخاب کنید و کلیدهای بالا را داخل قالب حلقه (Loop Item) استفاده نمایید. متاها با `register_post_meta` ثبت شده و در REST API هم در دسترس‌اند.

= فایل xls قدیمی باز نمی‌شود. =

در اکسل فایل را با گزینه Save As و فرمت Excel Workbook (*.xlsx) ذخیره کنید.

= ستون‌های اضافه فایل چه می‌شوند؟ =

کاملاً نادیده گرفته می‌شوند؛ فقط ۹ ستون اول (بر اساس ترتیب) پردازش می‌شوند.

= آیا فایل آپلودی در هاست ذخیره می‌شود؟ =

خیر، فایل فقط در لحظه خوانده می‌شود و پس از پایان درخواست از بین می‌رود.
