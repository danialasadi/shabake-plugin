# معرفی شبکه ایده پردازی

افزونه‌ای برای وردپرس که:

- **یک پست‌تایپ سفارشی** به نام «**مرکز**» (جمع: «**مراکز**»، اسلگ `idea_center`) می‌سازد؛
- **همه فیلدهای پست عادی وردپرس** را دارد (عنوان، ویرایشگر متن، نویسنده، تصویر شاخص، خلاصه، یادداشت‌بازتابی، فیلدهای سفارشی، دیدگاه‌ها و اصلاحات) و با آیکون اکسل در منوی داشبورد نمایش داده می‌شود؛
- **بخش «دسته بندی ها»** برای افزودن و مدیریت دسته‌بندی‌های سلسله‌مراتبی (زیر منوی «مراکز»، دستی و بدون ستون اکسل)؛
- **آپلود فایل اکسل/CSV** و **درون‌ریزی گروهی** (هر تعداد پست در یک مرحله) را ممکن می‌کند؛
- **فقط ۹ ستون اول** فایل را می‌خواند و ستون‌های اضافه را **کاملاً نادیده می‌گیرد**؛
- همه فیلدها را **متنی** ذخیره می‌کند.

## فیلدها و ترتیب ستون‌ها

| ستون | عنوان | ذخیره در |
|------|-------|----------|
| ۱ | نام مراکز | عنوان پست (`post_title`) — بدون meta key |
| ۲ | تعداد مراکز | متا `ei_center_count` |
| ۳ | تعداد استان | متا `ei_province_count` |
| ۴ | ایکون | متا `ei_icon` |
| ۵ | آدرس | متا `ei_address` |
| ۶ | شماره تماس | متا `ei_phone` |
| ۷ | آدرس وبسایت | متا `ei_website` |
| ۸ | نام شهر | متا `ei_city` |
| ۹ | نام استان | متا `ei_province_name` |
| ۱۰ به بعد | — | **نادیده گرفته می‌شود** |

> کلیدهای متا عمداً **بدون زیرخط اولیه** هستند تا در فهرست فیلدهای سفارشی وردپرس و در پویاسازهای **المنتور** نمایش داده شوند (کلیدهایی که با `_` شروع شوند «محافظت‌شده» و مخفی هستند).

## استفاده در المنتور

1. در ویرایشگر المنتور، یک ویجت/عنوان را انتخاب کنید و **پویاساز (Dynamic Tag) → فیلد سفارشی / Post Custom Field** را بزنید.
2. یکی از این کلیدها را وارد کنید:

   | فیلد | کلید (Meta Key) |
   |------|-----------------|
   | تعداد مراکز | `ei_center_count` |
   | تعداد استان | `ei_province_count` |
   | ایکون | `ei_icon` |
   | آدرس | `ei_address` |
   | شماره تماس | `ei_phone` |
   | آدرس وبسایت | `ei_website` |
   | نام شهر | `ei_city` |
   | نام استان | `ei_province_name` |
   | نام مراکز | ندارد — از پویاساز **عنوان نوشته (Post Title)** استفاده کنید |

3. این کلیدها در بخش «مشخصات مرکز» کنار هر فیلد هم نمایش داده می‌شوند.

نکته: پست‌تایپ «مراکز» اکنون **عمومی** است (آرشیو با اسلگ `/markaz/`) تا در Theme Builder و ابزارک «نوشته‌ها»ی المنتور هم قابل انتخاب باشد؛ پس از به‌روزرسانی افزونه یک بار آن را غیرفعال و دوباره فعال کنید تا قوانین بازنویسی URL تازه شوند.

## بخش «دسته بندی ها»

زیر منوی «مراکز»، بخشی به نام **«دسته بندی ها»** وجود دارد:

- **افزودن:** نام دسته را وارد و ذخیره کنید (مدیریت دستی؛ ستونی در اکسل ندارد).
- **سلسله‌مراتبی:** مثل دسته‌بندی‌های نوشته می‌توانید دسته والد/فرزند داشته باشید.
- **در ویرایش هر مرکز:** جعبه «دسته بندی ها» زیر ویرایشگر برای انتخاب دسته‌ها.
- **در جدول لیست:** ستون «دسته بندی ها» نشان می‌دهد هر مرکز در کدام دسته‌هاست؛ با کلیک روی هر دسته، فهرست فیلتر می‌شود.
- **در المنتور:** با پویاسازهای دسته‌بندی (نام، توضیحات، لینک، تصویر) و با **فیلتر Taxonomy Filter** در Loop Grid.
- آدرس آرشیو هر دسته: `/markaz-category/<نام-دسته>/`

## سازگاری با Loop Grid (حلقه) المنتور

افزونه برای ویجت **Loop Grid** و ابزارک «نوشته‌ها»ی المنتور آماده است:

1. **به‌روزرسانی:** زیپ جدید را نصب کنید و افزونه را یک بار غیرفعال/فعال کنید.
2. **ساخت قالب حلقه:** المنتور → قالب‌ها → افزودن → **«حلقه / Loop Item»**؛ داخل آن «عنوان نوشته» و «تصویر شاخص» را بگذارید و برای فیلدها با پویاساز **فیلد سفارشی** کلیدهای `ei_center_count` ،`ei_province_count` ،`ei_icon` ،`ei_address` ،`ei_phone` ،`ei_website` ،`ei_city` ،`ei_province_name` را استفاده کنید.
3. **افزودن Grid:** ویجت **Loop Grid** را در صفحه قرار دهید و در بخش پرس‌وجو:
   - شامل بر اساس → **نوع پست** → ☑ **مراکز**
   - قالب حلقه → قالبی که ساختید
4. هر «مرکز» به‌صورت یک کارت با هر فیلدی که در قالب حلقه تعریف کرده‌اید نمایش داده می‌شود؛ مرتب‌سازی، صفحه‌بندی و شرط‌های نمایش همگی توسط خود المنتور کنترل می‌شوند.

چرا سازگار است (این موارد با تست خودکار کنترل می‌شوند):

- پست‌تایپ `public`، `publicly_queryable`، `show_ui` و `show_in_rest` دارد → در پرس‌وجوی Loop Grid قابل انتخاب است
- پشتیبانی از `title` و `thumbnail` → تصویر شاخص داخل قالب حلقه کار می‌کند
- هر ۸ فیلد با `register_post_meta()` ثبت شده‌اند و در REST API هم دیده می‌شوند
- کلیدهای متا بدون زیرخط هستند و در پویاسازها ظاهر می‌شوند

نکته: «دسته بندی ها» **دسته‌بندی واقعی** (`idea_category`) است؛ می‌توانید در Loop Grid از **فیلتر دسته‌بندی (Taxonomy Filter)** استفاده کنید.

## فیلتر حلقه (Loop Grid): دسته بندی، استان و شهر

افزونه یک ویجت المنتور به نام **«فیلتر حلقه (دسته بندی، استان، شهر)»** در دسته «شبکه ایده پردازی» اضافه می‌کند که یک ویجت **Loop Grid** (یا «نوشته‌ها») را بر اساس دسته‌بندی، استان، شهر و جستجوی نام فیلتر می‌کند.

### راه‌اندازی (سه مرحله)

1. **Loop Grid:** در ویجت Loop Grid، بخش پرس‌وجو → **شناسه کوئری (Query ID)** را باز کنید و مقداری مثل `centers` بنویسید. منبع پرس‌وجو را «مراکز» بگذارید.
2. **ویجت فیلتر:** ویجت «فیلتر حلقه» را بالای Loop Grid قرار دهید و در «شناسه کوئری» همان `centers` را وارد کنید. اگر این فیلد خالی بماند، فیلتر روی همه حلقه‌های «مراکز» همان صفحه اعمال می‌شود.
3. **ظاهر و رفتار:** نمایش/پنهان کردن هر فیلد، متن گزینه «همه»، اعمال خودکار بدون دکمه، محدود شدن فهرست شهرها به استان انتخاب‌شده، تایپوگرافی، رنگ‌ها، حاشیه و شعاع گوشه‌ها.

> Loop Grid یکی از ویجت‌های Elementor Pro است؛ ویجت فیلتر با آن و با ویجت «نوشته‌ها»ی المنتور کار می‌کند.
>
> فیلتر روی همان کوئری‌ای اعمال می‌شود که Loop Grid اجرا می‌کند (`Elementor_Post_Query`): هم از راه Query ID و هم بدون آن (از طریق `pre_get_posts`). بنابراین با «Current Query»/آرشیو، صفحه‌بندی معمولی و صفحه‌بندی AJAX (Load More / Infinite Scroll) هم سازگار است.

### استان‌ها و شهرها

- دو تاکسونومی تازه: **`idea_province`** (استان) و **`idea_city`** (شهر) — کنار «دسته بندی ها» زیر منوی «مراکز».
- **۳۱ استان و بیش از ۷۰۰ شهر ایران** خودکار ساخته می‌شوند (هنگام فعال‌سازی و همچنین نخستین ورود به پیشخوان پس از به‌روزرسانی).
- هر مرکز از روی ستون‌های **«نام استان»** و **«نام شهر»** به این تاکسونومی‌ها وصل می‌شود؛ اگر استان یا شهر وجود نداشته باشد **خودکار ساخته می‌شود**.
- «استان فارس» و «فارس» یکی هستند: پیشوند «استان» حذف و حروف عربی (ي، ك) اصلاح می‌شود.
- شهرهای هم‌نام در استان‌های مختلف با پسوند استان ذخیره می‌شوند: «فیروزآباد (کرمانشاه)».
- منوی **«مراکز ← استان و شهر»**: فهرست استان‌ها، تعداد شهرها و دکمه **هم‌گام‌سازی دوباره** برای مراکزی که پیش از این نسخه درون‌ریزی شده‌اند.

### پارامترهای URL

| پارامتر | معنی |
|---|---|
| `shabake_cat` | اسلاگ دسته بندی (زیردسته‌ها هم شامل می‌شوند) |
| `shabake_province` | اسلاگ استان |
| `shabake_city` | اسلاگ شهر |
| `shabake_s` | عبارت جستجو |

فیلترها با متد GET ارسال می‌شوند؛ صفحه‌بندی به صفحه اول برمی‌گردد و بقیه پارامترهای آدرس حفظ می‌شوند. برای صفحه‌بندی AJAX (Load More) آخرین فیلتر در کوکی `shabake_filter` نگه داشته می‌شود تا صفحه بعدی هم فیلترشده بماند.

## نصب

1. پوشه `idea-network` را در `wp-content/plugins/` کپی کنید (یا آن را به‌صورت فایل ZIP بسته‌بندی و از «افزودن افزونه → بارگذاری افزونه» آپلود کنید).
2. افزونه را فعال کنید.
3. منوی جدید **مراکز** ظاهر می‌شود.

## استفاده

1. به **مراکز → درون‌ریزی اکسل** بروید.
2. فایل را انتخاب کنید (xlsx، xlsm یا csv).
3. در صورت نیاز تنظیمات را تغییر کنید:
   - **وضعیت پست‌ها:** منتشرشده / پیش‌نویس / در انتظار بررسی / خصوصی
   - **ردیف اول سرستون است:** پیش‌فرض روشن؛ اگر فایل شما سرستون ندارد آن را بردارید.
   - **به‌روزرسانی مرکزِ هم‌نام:** اگر تیک بخورید، به‌جای ساخت پست تکراری، مرکزِ موجود با همان نام به‌روزرسانی می‌شود (برای ایمپورت مجدد فایل‌ها مفید است).
4. روی **درون‌ریزی فایل** بزنید؛ گزارش شامل تعداد ایجادشده‌ها، به‌روزرسانی‌شده‌ها، ردیف‌های رد شده (با شماره ردیف و دلیل) و خطاها نمایش داده می‌شود.

دکمه **دانلود نمونه فایل CSV** یک فایل نمونه با سرستون فارسی (UTF-8 با BOM، قابل باز شدن در اکسل) تحویل می‌دهد.

### قوانین درون‌ریزی

- فقط ۹ ستون اول خوانده می‌شود؛ ستون‌های ۱۰ به بعد هرچه باشند نادیده گرفته می‌شوند.
- ردیف‌های کاملاً خالی نادیده گرفته می‌شوند.
- ردیف‌هایی که **نام مراکز** (ستون اول) خالی دارند وارد نمی‌شوند و در گزارش با شماره ردیف اصلی فایل فهرست می‌شوند.
- شماره ردیف‌ها همان شماره واقعی ردیت در فایل اکسل/CSV است (حتی اگر ردیف‌های خالی وسط کار وجود داشته باشد).

## فرمت‌های پشتیبانی‌شده

| فرمت | وضعیت |
|------|-------|
| `.xlsx` / `.xlsm` | ✅ خوانده می‌شود (پارسر اختصاصی، بدون کتابخانه خارجی) |
| `.csv` / `.txt` | ✅ با جداکننده خودکار (`,` `;` Tab) و کدگذاری UTF-8 / UTF-16 / Windows-1256 |
| `.xls` (قدیمی) | ❌ پیام راهنما می‌دهد: ابتدا در اکسل با «Save As → Excel Workbook (*.xlsx)» ذخیره کنید |

نکته: فایل آپلودی فقط **خوانده می‌شود** و هرگز در هاست ذخیره نمی‌شود.

## پیش‌نیازها

- وردپرس 6.0+ و PHP 7.4+
- اکستنشن `zip` (بخوانید `ZipArchive`) برای فایل‌های xlsx — روی اکثر هاست‌ها فعال است
- `mbstring` یا `iconv` برای تبدیل کدگذاری فایل‌های CSV قدیمی

## تغییر نام پست‌تایپ یا فیلدها

همه در یک جا تعریف شده‌اند: `idea-network/includes/class-excel-cpt.php`

- اسلگ پست‌تایپ: ثابت `POST_TYPE` (مقدار فعلی: `idea_center`)
- برچسب‌ها: متد `register()`
- ستون‌ها/فیلدها و ترتیب‌شان: متد `get_columns_map()` — کافی است برچسب یا کلید متا را تغییر دهید؛ فرم متا‌باکس، ستون‌های جدول لیست و ایمپورت اکسل همگی خودکار از همین آرایه پیروی می‌کنند.

## فیلترهای قابل استفاده (برای توسعه‌دهندگان)

```php
// سقف تعداد ردیف در هر ایمپورت (پیش‌فرض ۵۰۰۰)
add_filter( 'idea_network_max_rows', function () { return 10000; } );

// سقف حجم فایل به بایت (پیش‌فرض ۱۰ مگابایت)
add_filter( 'idea_network_max_file_size', function () { return 20 * 1024 * 1024; } );

// فرمت‌های مجاز (پیش‌فرض xlsx، xlsm، csv)
add_filter( 'idea_network_allowed_extensions', function () { return array( 'xlsx', 'csv' ); } );
```

## امنیت

- بررسی `nonce` روی همه فرم‌ها و درخواست‌ها (`check_admin_referer`)
- بررسی کپابیلیتی `manage_options` قبل از هر عملیات
- اعتبارسنجی اکستنشن، خطاهای آپلود و حجم فایل
- پاک‌سازی ورودی‌ها هنگام ذخیره (`sanitize_text_field`, `sanitize_key`, `wp_unslash`) و خروجی امن (`esc_html`, `esc_attr`, `esc_url`)
- بدون ذخیره فایل آپلودی روی سرور (فقط پارس از فایل موقت PHP)

## محدودیت‌های شناخته‌شده

- فایل‌های `.xls` قدیمی پشتیبانی نمی‌شوند (پیام راهنما نمایش داده می‌شود).
- سلول‌های تاریخ اکسل به‌صورت سریال عددی خوانده می‌شوند؛ چون فیلدهای شما همگی متنی هستند انتظار نمی‌رود مشکلی پیش بیاید.
- درون‌ریزی همزمان (همان لحظه) انجام می‌شود؛ برای فایل‌های بسیار بزرگ سقف ۵۰۰۰ ردیف اعمال می‌شود (قابل افزایش با فیلتر بالا).

## تست‌ها

پوشه `tools/` شامل تست‌های خودکار است (PHP CLI لازم دارد؛ بدون نیاز به وردپرس):

```powershell
php tools/run-tests.php        # تست‌ها: پارسر xlsx/CSV، نگاشت ۹ ستون، حلقه درون‌ریزی، فایل واقعی openpyxl
php tools/loop-filter-test.php # تست ویجت فیلتر، تاکسونومی استان/شهر، ساخت ترم‌ها و اعمال فیلتر روی کوئری
php tools/smoke-load.php       # تست بوت‌شدن فایل اصلی افزونه با استاب‌های وردپرس
php tools/dump-rows.php file.xlsx   # نمایش ردیف‌های خوانده‌شده یک فایل (ابزار دیباگ)
php tools/build-sample-xlsx.php     # تولید فایل نمونه xlsx دستی
python tools/build-real-xlsx.py     # تولید فایل xlsx واقعی با openpyxl (اختیاری، نیازمند pip install openpyxl)
```
